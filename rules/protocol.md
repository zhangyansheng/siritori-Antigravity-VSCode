# 歴史出来事しりとり プロトコル・ルール共通仕様書 (Protocol v1.0 / Game Rule v6.1)

## 1. 概要
- ゲームテーマ: 日本史における歴史の出来事および歴史人物。
- しりとり方式: 「識別子読み」によるしりとり。後半呼称（戦い、合戦、変、乱、事件、事変、一揆、戦争、条約）および連結の「の」は連鎖に関与しない。
- 参加エージェント: Judge（指揮者・審判）、PlayerA（戦略家）、PlayerB（歴史学者）、PlayerC（ユーモア）。

## 2. メッセージプロトコル
- すべての通信は JSON オブジェクトで行われる。
- `TURN_INSTRUCTION` (Judge -> Player):
  - `game_id`, `turn`, `required_prefix`, `prefix_reason`, `scores`, `history` を含む。
- `TURN_REPLY` (Player -> Judge):
  - `in_reply_to`, `status` ("answered" / "cannot_answer" / "tool_error"), `answer`, `event_info`, `comment` を含む。
  - 出力は必ず **有効な JSON のみ** を返さなければならない。

## 3. 回答の条件
1. 日本語表記（かな・漢字を含む）。
2. フル表記が4文字以上（空白除く）。
3. 歴史データソース（Wikipedia日本語版、Wikidata等）で実在を確認できること。
4. 日本史の歴史出来事・人物であり、11分類（合戦名/戦い名/乱/事件名/戦争名/一揆/人物名/地名/時代名/条約名/組織名）のいずれかに適合すること。
5. 識別子読みが2文字以上であること。
6. 識別子読みが必要頭文字列に適合すること（清音化して照合）。
7. 識別子読みがこれまでの履歴と完全一致で既出でないこと。
8. 制限時間60秒以内に返信すること。

## 4. 人格と選択方針
- PlayerA（戦略家）: 勝利最優先。次のPlayerが答えにくい語尾（「る」「ぬ」「ん」終わり、拗音終わり等）の識別子を優先。
- PlayerB（歴史学者）: 教育的価値優先。歴史的意義が深く、教科書でも扱われる重要な合戦・事件・条約を優先。
- PlayerC（ユーモア）: 意外性・豆知識重視。珍しい分類や興味深いトリビアを持つ人物・出来事を優先。
